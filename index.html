What is Oat UI?

Oat is a lightweight, zero-dependency UI framework that styles semantic HTML automatically. No class soup required.

How big is it?

Around 6 KB CSS and 2.2 KB JS gzipped — tiny enough to inline.

Does it work with frameworks?

Yes — Oat is framework-agnostic. Drop in the CDN links or install via npm and import the files.
